SECTION 9: Boolean Expressions & Flow Control Operators
----------------------------------------------------------
Topics:
  Boolean Functions:
    bool()           — convert any value to True/False (falsy: 0, "", None, [])
    all([...])       — True only if every value is truthy
    any([...])       — True if at least one value is truthy
    isinstance()     — check if a value belongs to a specific data type
    String/number methods returning bool: .startswith(), .endswith(),
                                           .isnumeric(), .isalpha(), .is_integer()

  Comparison Operators:
    ==, !=, <, <=, >, >=
    Chain comparison: 18 <= age <= 30  (Python's BETWEEN)
    Rules: = is assignment, == is comparison; strings compared alphabetically; case-sensitive

  Logical Operators:
    and  — both conditions must be True
    or   — at least one condition must be True
    not  — flips True/False
    Execution order: and has higher priority than or
    Use parentheses to control order when mixing and + or

  Membership Operators:
    in     — value exists inside a string/list/sequence
    not in — value does NOT exist

  Identity Operators:
    is     — same object in memory (not same value)
    is not — different object in memory
    Rule: always use is / is not when comparing against None

Study Notes: Full reference summary of all operators with examples and data analysis use cases
